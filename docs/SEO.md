# SEO и доступность

## Сделано
- Заголовок и описание на каждой странице (`usePageMeta`), `lang` меняется по версии сайта.
- Адреса `/ru/...` и `/kk/...`, ссылки hreflang между версиями, `robots.txt` (закрывает `/admin`), `sitemap.xml` (генерируется при сборке: основные страницы + опубликованные товары на обоих языках).
- Семантическая разметка (header/nav/main/footer, заголовки, `address`), подписи у форм и кнопок, пропускающая ссылка, фокус с клавиатуры, учёт `prefers-reduced-motion`, ленивая загрузка фото, состояния загрузки/ошибки.
- Базовые теги Open Graph в `index.html`.

## Ограничения статичного сайта (SPA)
1. Страницы собираются в браузере из JavaScript. Google обычно выполняет JS, но индексирует медленнее; многие мессенджеры и соцсети JS **не** выполняют.
2. Поэтому при отправке ссылки на товар в WhatsApp/Telegram/Instagram превью покажет **общие** название и описание сайта, а не конкретного товара и его фото. Теги hreflang и title товара также добавляются скриптом.
3. Нет `og:image` и данных schema.org (Product) — их можно добавить только предрендером или серверной частью.
4. Sitemap обновляется только при новой сборке: новые товары попадут в него после следующего деплоя.
5. Улучшение при необходимости: предрендер страниц на этапе сборки или Cloudflare Pages Functions для OG-тегов (потребует отдельной работы и учёта лимитов Workers).

Автоматические проверки доступности (axe/Lighthouse) и проверка в реальных браузерах и на телефоне **не проводились** — сделайте вручную перед запуском.
