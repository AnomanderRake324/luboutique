# Как управлять сайтом с телефона

Откройте `адрес-сайта/admin`, войдите email и паролем. Добавьте страницу на главный экран телефона, чтобы заходить быстрее.

**Добавить товар:** Товары → «+ Добавить» → нажмите «+ Добавить фото» (из галереи или камеры) → заполните название, цену, размеры, цвета → «Сохранить черновик» или «Опубликовать». Первое фото — обложка; порядок меняют кнопками ← →.
**Скрыть товар:** «Снять» (вернётся в черновики) или «В архив». **Удалить** — навсегда, вместе с фото.
**Категории:** раздел «Категории». **Коллекции:** создать, отметить товары, включить «Показывать на сайте».
**Баннеры:** раздел «Баннеры» → шаблон → фото → текст → «Опубликовать». «Скачать PNG» — картинка для Instagram.
**Главная:** отметьте товары для «Избранного» и «Новинок».
**Настройки:** название, логотип, номер WhatsApp, адрес, соцсети. **Раз в неделю нажимайте «Скачать копию данных».**

Казахские поля можно оставить пустыми — тогда на казахской версии покажется русский текст.
Заказ через WhatsApp — это сообщение вам; заказ считается принятым, когда вы ответили покупателю.
Раз в неделю заходите в админку: так бесплатная база Supabase реже уходит на паузу. Если сайт пишет «Не удалось загрузить данные» — откройте supabase.com, свой проект и нажмите Resume project.
